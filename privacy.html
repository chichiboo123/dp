개인정보 처리방침

시행일: 2026년 10월 16일 · 버전 1.0 (최초 제정)

교육뮤지컬 꿈꾸는 치수쌤(이하 “운영자”)은 웹 서비스 디지털 페이퍼(https://dp.chichiboo.link, 이하 “서비스”)를 운영하면서 「개인정보 보호법」 제30조 및 같은 법 시행령 제31조, 개인정보보호위원회의 「개인정보 처리방침 작성지침」에 따라 정보주체의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

info 서비스는 별도의 서버(백엔드)나 데이터베이스 없이 이용자의 브라우저 안에서만 동작합니다. 운영자는 회원가입을 받지 않으며, 학습지·필기·입력 내용과 같은 이용자의 개인정보를 수집하거나 저장하지 않습니다.

주요 개인정보 처리 표시

cloud_off
서버 저장 없음학습지·필기 내용은 이용자 기기에서만 처리
person_off
수집 항목 없음회원가입·이름·이메일 등 수집하지 않음
lock
읽기 전용 권한구글 드라이브 drive.readonly 권한만 요청
block
제3자 제공 없음광고·분석 도구 미사용, 제3자 제공 없음

제1조 (개인정보의 처리 목적)

운영자는 서비스 제공을 위하여 개인정보를 별도로 수집·저장하지 않습니다. 다만 이용자가 구글 드라이브 연동 기능을 선택한 경우에 한하여, 다음의 목적을 위해 이용자의 브라우저 안에서 구글 인증 정보를 일시적으로 처리합니다. 처리한 정보는 다음의 목적 이외의 용도로는 이용되지 않으며, 이용 목적이 변경되는 경우에는 「개인정보 보호법」 제18조에 따라 별도의 동의를 받는 등 필요한 조치를 이행할 예정입니다.

  1. 구글 드라이브 파일 불러오기: 교사(이용자)가 구글 드라이브에서 선택한 PDF·JPG·PNG 학습지를 화면에 불러오기 위한 인증
  2. 로그인 상태 유지: 새로고침 시 다시 로그인하지 않도록 인증 토큰의 만료 시각까지 로그인 상태 유지

제2조 (처리하는 개인정보의 항목)

① 운영자는 회원가입 절차가 없으며, 이름·이메일·전화번호·학번 등 이용자를 식별할 수 있는 정보를 수집하지 않습니다.

② 서비스 이용 과정에서 다음 정보가 이용자의 기기(브라우저) 안에서만 처리되며, 운영자에게 전송되지 않습니다.

구분처리 항목처리 위치·방법
구글 로그인(선택) 구글 OAuth 액세스 토큰, 토큰 만료 시각 브라우저 localStorage에 저장(약 1시간 후 자동 만료·삭제). 앱은 구글 계정의 이름·이메일·프로필 정보를 요청하지 않습니다.
학습지 파일 이용자가 선택한 PDF·JPG·PNG 파일 내용 구글 드라이브 또는 이용자 기기에서 브라우저로 직접 불러와 메모리에서만 처리
필기·입력 내용 펜·형광펜 필기, 글상자 입력 내용, 체크박스 상태 브라우저 메모리에서만 처리하며, 페이지를 닫거나 새로고침하면 사라짐. JPG/PDF 저장 시 이용자 기기에만 저장
공유 링크(교사) 구글 드라이브 파일 ID, 시작 페이지, 제출 링크 주소, 교사가 만든 글상자·체크박스의 위치와 입력 내용 교사가 [공유]를 누를 때 URL 주소에 담겨 클립보드로 복사됨. 운영자 서버에 저장되지 않음
화면 설정 브라우저 언어 설정 표시 언어(한국어·영어·일본어) 자동 선택에만 사용, 저장하지 않음
warning 공유 링크에는 교사가 글상자에 미리 입력한 내용이 그대로 포함됩니다. 학생 이름 등 개인정보를 글상자에 입력한 상태로 공유하지 마세요. 학생이 학습지에 입력한 내용은 공유 링크에 담기지 않으며, 학생이 직접 저장·제출한 파일만 제출처로 전달됩니다.

③ 서비스 접속 시 웹 호스팅 및 외부 라이브러리 제공 과정에서 IP 주소, 브라우저 종류, 접속 일시 등 기술 정보가 제6조의 외부 서비스 제공자에 의해 자동으로 생성·처리될 수 있습니다. 운영자는 이 정보를 별도로 수집·열람·이용하지 않습니다.

제3조 (개인정보의 처리 및 보유 기간)

운영자는 개인정보를 보유하지 않습니다. 이용자의 기기에서 처리되는 정보의 보존 기간은 다음과 같습니다.

  1. 구글 액세스 토큰: 발급 시점부터 최대 약 1시간(구글이 정한 만료 시각). 만료되거나 [로그아웃] 시 즉시 삭제
  2. 학습지·필기·입력 내용: 브라우저 탭을 닫거나 새로고침할 때까지(메모리에만 존재)
  3. 공유 링크: 별도 보관하지 않으며, 링크를 전달받은 사람이 보관하는 동안 유효

제4조 (개인정보의 파기 절차 및 방법)

① 운영자는 개인정보를 보유하지 않으므로 별도의 파기 대상이 없습니다.

② 이용자의 기기에 남는 정보는 다음 방법으로 파기됩니다.

  1. 구글 액세스 토큰: 만료 시 앱이 localStorage에서 자동 삭제하며, [로그아웃] 시 삭제와 함께 구글에 토큰 무효화(revoke)를 요청합니다.
  2. 학습지·필기 내용: 브라우저 탭 종료 또는 새로고침 시 메모리에서 소멸하여 복구할 수 없습니다.
  3. 이용자가 저장한 JPG·PDF 파일: 이용자 기기의 파일이므로 이용자가 직접 삭제합니다.

제5조 (개인정보의 제3자 제공)

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 교사가 설정한 제출처(Padlet·Canva 등)에 학생이 직접 파일을 업로드하는 행위는 이용자 본인과 해당 서비스 사이에서 이루어지며, 해당 서비스의 개인정보 처리방침이 적용됩니다.

제6조 (개인정보 처리업무의 위탁, 외부 서비스 이용 및 국외 이전)

① 운영자는 개인정보 처리업무를 위탁하지 않으며, 운영자가 보유한 개인정보를 국외로 이전하지 않습니다.

② 다만 서비스는 정적 웹페이지 형태로 아래 외부 서비스를 통해 제공·구동되며, 이용자의 브라우저가 해당 서비스에 직접 접속하는 과정에서 IP 주소, 브라우저 정보, 접속 일시 등이 각 사업자에게 전송되어 국외(주로 미국 등)에서 처리될 수 있습니다. 해당 정보의 처리는 각 사업자의 개인정보 처리방침에 따릅니다.

제7조 (구글 사용자 데이터의 이용)

  1. 서비스는 구글 드라이브에 대하여 읽기 전용 권한(https://www.googleapis.com/auth/drive.readonly)만 요청하며, 이용자의 드라이브 파일을 생성·수정·삭제하지 않습니다.
  2. 구글 API를 통해 받은 정보는 이용자가 직접 선택한 학습지 파일을 화면에 표시하는 목적으로만 브라우저 안에서 사용하며, 운영자 서버로 전송하거나 저장·판매·광고 목적으로 이용하지 않고, 사람이 열람하지 않습니다.
  3. 서비스의 구글 API 수신 정보 이용 및 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 준수합니다.
    Digital Paper's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  4. 이용자는 언제든지 구글 계정 › 보안 › 타사 앱 및 서비스에서 서비스에 부여한 접근 권한을 철회할 수 있습니다.

제8조 (만 14세 미만 아동의 개인정보)

  1. 학생은 교사가 전달한 공유 링크로 로그인 없이 서비스를 이용하며, 운영자는 만 14세 미만 아동을 포함한 학생의 개인정보를 수집하지 않습니다. 따라서 「개인정보 보호법」 제22조의2에 따른 법정대리인 동의 절차를 두지 않습니다.
  2. 구글 로그인 기능은 학습지를 만들고 배포하는 교사를 위한 기능입니다. 만 14세 미만 아동이 구글 계정으로 로그인하려는 경우 구글의 아동 계정 정책(Family Link 등)이 적용됩니다.
  3. 교사는 학습지를 만들 때 학생 이름·연락처 등 개인정보가 공유 링크에 포함되지 않도록 유의하고, 학생에게 불필요한 개인정보를 학습지에 적지 않도록 안내해 주시기 바랍니다.

제9조 (정보주체와 법정대리인의 권리·의무 및 행사방법)

① 정보주체는 운영자에 대하여 언제든지 「개인정보 보호법」 제35조부터 제37조까지에 따른 개인정보 열람, 정정·삭제, 처리정지 및 동의 철회 등의 권리를 행사할 수 있습니다.

② 권리 행사는 제13조의 연락처로 서면, 전자우편 등을 통하여 할 수 있으며, 운영자는 이에 대해 지체 없이 조치하겠습니다. 다만 운영자는 개인정보를 보유하지 않으므로, 이용자 기기에 저장된 정보는 다음 방법으로 이용자가 직접 즉시 삭제·철회할 수 있습니다.

  1. 구글 로그인 정보 삭제: 화면 상단 메뉴의 [로그아웃] 또는 브라우저의 사이트 데이터 삭제
  2. 구글 드라이브 접근 권한 철회: 구글 계정 권한 관리 페이지
  3. 필기·입력 내용 삭제: [초기화] 버튼, 탭 닫기 또는 새로고침

③ 권리 행사는 정보주체의 법정대리인이나 위임을 받은 자 등 대리인을 통하여 할 수 있으며, 이 경우 「개인정보 처리 방법에 관한 고시」 별지 제11호 서식에 따른 위임장을 제출하여야 합니다.

④ 정보주체는 개인정보 보호 관련 법령을 위반하여 타인의 개인정보와 사생활을 침해하여서는 안 됩니다.

제10조 (개인정보의 안전성 확보조치)

운영자는 「개인정보 보호법」 제29조에 따라 다음과 같은 조치를 하고 있습니다.

  1. 최소 수집·최소 권한: 개인정보를 수집하지 않으며, 구글 API 권한은 읽기 전용 범위 하나로 제한합니다.
  2. 서버 미저장 구조: 학습지와 필기 데이터는 운영자 서버를 거치지 않고 이용자 브라우저와 구글 서버 사이에서만 직접 통신합니다.
  3. 전송 구간 암호화: 서비스와 외부 API 통신은 모두 HTTPS(TLS)로 암호화됩니다.
  4. 인증 정보 관리: 액세스 토큰은 약 1시간 후 자동 만료되며, 로그아웃 시 즉시 삭제 및 무효화합니다. OAuth 클라이언트는 등록된 도메인에서만 동작하도록 제한하고, API 키에는 HTTP 리퍼러 제한을 적용합니다.
  5. 비밀정보 관리: 배포용 인증 설정값은 소스 코드에 포함하지 않고 GitHub Actions 비밀값(Secrets)으로 관리합니다.
